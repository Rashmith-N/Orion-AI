# ORION AI

A futuristic, mobile-first AI assistant interface.

## Current version

This version includes:
- Responsive AI chat UI
- Animated cosmic background
- Animated Orion orb
- Chat and Search modes
- File attachment interface
- Voice input interface
- Dark/light mode
- New chat
- Quick prompts
- Streaming-style demo responses

## Important

This is the **frontend foundation**. The current chat uses demo responses. A real AI backend has not been connected yet.

For a production AI:
1. Deploy this frontend.
2. Create a secure backend/serverless API.
3. Store AI API keys only on the server.
4. Connect the backend to an AI model provider.
5. Add web search, document processing, image analysis, authentication, rate limits, and usage controls.

Never put a private AI API key directly in `script.js` or other public frontend files.
